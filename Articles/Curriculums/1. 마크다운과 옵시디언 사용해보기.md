
## 개요

마크다운 문법, 들어보셨나요?
편집 도구(노션, 워드, 메모 등등)에서 글자를 드래그하고 cmd+B 를 누르면 글자가 굵게 변합니다. 이렇게 굵게 변한 글자는 마크다운 문법으로는 `**글자**` 이렇게 쓰인답니다. 
글자 양옆에 띄어쓰기 없이 별 두개를 입력해서 굵게 만드는 것, 이게 바로 마크다운 문법입니다. 이 강력하고 편리한 문법은 .md 확장자를 가진 파일에서 작용하죠.

옵시디언은 마크다운 문법을 기본으로 하는 강력한 문서 툴입니다. 다음 항목에 대해 각 **최대 5분** 정도 조사해봅시다.

1. 마크다운 문법이 뭘까?
2. md 파일이란 뭐고 어디에 쓰일까?
3. 옵시디언이란? 왜 옵시디언이지?

직접 사용해볼까요?

### 0. 그 전에,

닉네임을 설정해봅시다! 반드시 영어이름 소문자여야 해요. 이 닉네임은 앞으로 계속해서 쓰일테니, 고유한 이름으로 해주세요. 저의 경우 sujileelea입니다. 

https://github.com/ 으로 접속해서 이 닉네임이 사용가능한 닉네임인지 확인 후 계정을 생성해주세요. 이 닉네임은 식별자이기 때문에, "나"라는 걸 드러내야하니 대충 짓지 마세요.

### 4. 파일 트리 생성하기

- What is file tree? 이제 패턴을 알죠? **최대 5분** 조사해봅시다. 어려운 말인 것 같지만 직접 해보면 굉장히 쉽고 효율적인 단어라는 것을 알게 된답니다.

1. 앞선 **"1. 옵시디언 다운로드"** 단계에서 데스크탑에 볼트를 생성했습니다. 해당 볼트의 이름을 "vault-{닉네임}"으로 변경해주세요. 깃허브 닉네임과 **완전** **동일**해야합니다. 
2. 데스크탑에 "Lea-Loft-{닉네임}"이라는 폴더를 생성합니다. 그리고, 앞서 만들었던 나의 볼트를 해당 폴더 안으로 넣어주세요.
3. 자신의 폴더 아래에 파일(== 노트, 문서)을 생성해주세요. 이름은 "Curriculums-1-마크다운과-옵시디언-사용해보기" 로 합시다.
4. 이제 finder/탐색기로 실제 우리가 만든 파일 트리를 확인해볼 수 있습니다!
    1. 아주 쉽게 시각적으로 확인
    2. `~/Desktop/Lea-Loft-{닉네임}/vault-{닉네임}/Curriculums-1-마크다운과-옵시디언-사용해보기.md` 또는 `/Users/{사용자이름}/Desktop/Lea-Loft-{닉네임}/vault-{닉네임}/Curriculums-1-마크다운과-옵시디언-사용해보기.md` 같은 경로 형태로 확인
    3. 뭐가 됐든 위와 같다면 성공! 저의 경우라면 `/Users/sujilee/Desktop/Lea-Loft-sujileelea/vault-sujileelea/Curriculums-1-마크다운과-옵시디언-사용해보기.md` 입니다.
    4. 위와 같이가 뭐지? 나 맞게 한거야? → 확인될때까지 조사해봅시다. 
5. 엇 그런데, 갑자기 볼트가 열리지 않거나 경로를 찾을 수 없대요. 왤까요? 🤔
6. 옵시디언이 **로컬** 기반이라 그렇습니다. 기존 `~/Desktop/vault-{닉네임}`이었던 볼트의 경로가, ``~/Desktop/Lea-Loft-{닉네임}/vault-{닉네임}`` 로 바뀌어서 그런거예요.
7. 옵시디언을 끄고, 다시 한 번 열어봅시다.

### 5. 마크다운 문서 작성

앞선 **"4. 파일 트리 생성하기"** 단계에서 `Curriculums-1-마크다운과-옵시디언-사용해보기` 문서를 생성했습니다. 해당 문서에 오늘 배운 내용을 정리해봅시다.

- 최대 50줄 이상 쓸 것. "뭘 채울지 모르겠어요"는 안돼요~
    - 50줄인지 어떻게 확인해요? → 옵시디언에서 줄 수 확인하는 방법을 검색해봅시다. 똑쟁이 여러분은 이제 이런 가이드도 필요없겠죠?
- 반드시 마크다운을 활용할 것.
    - 레아가 봤을 때 오~ 라는 말이 나오도록! 마지막 힌트를 드리자면, 이런 방법도 있어요
    - AI에게 "이거 마크다운으로 보기 좋게 정리해줘. 다른 팀원들과 볼거니 가독성이 중요해. 내용은 수정하지 말고 마크다운 문법만 추가해." 정도면 충분해요. 간혹 어떤 AI는 이모지나 색상 콜아웃을 넣어주는데, 이건 AI에게 다시 프롬프팅하거나 직접 수정하시면 됩니다.
